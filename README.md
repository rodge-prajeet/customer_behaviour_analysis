# customer_behaviour_analysis

Data analysis project showcasing customer behavior analysis using Python, SQL, Power BI

📊 Data Analytics Project

Overview

An end-to-end Data Analytics project focused on transforming raw data into meaningful business insights. The project covers data cleaning, EDA, SQL analysis, Power BI visualization, reporting, and presentation.
Dataset
The dataset was loaded and analyzed using Python. Data was cleaned by handling missing values, duplicates, inconsistent data, and incorrect data types.
Tools & Technologies

- Python
- Pandas & NumPy
- Matplotlib & Seaborn
- SQL
- PostgreSQL / MySQL / SQL Server
- Power BI
- Jupyter Notebook
- Gamma
- 
Project Workflow

Data Loading → Data Cleaning → EDA → SQL Analysis → Insights → Power BI Dashboard → Report → Presentation

Key Analysis

- Performed data cleaning and preprocessing
- Conducted Exploratory Data Analysis
- Used SQL to analyze business data and identify trends
- Calculated important KPIs and performance metrics
- Identified patterns, trends, and key business insights
- 
Power BI Dashboard

Created an interactive Power BI dashboard with KPIs, charts, filters, and business insights to make the analysis easy to understand and explore.
Results
The project transformed raw data into clear, actionable business insights, helping identify important trends, customer/product behavior, and areas requiring attention.
Presentation & Report
Created a professional analytical report and a Gamma presentation to communicate the methodology, findings, insights, and recommendations clearly.


Conclusion

This project demonstrates practical skills in Data Cleaning, Python, SQL, EDA, Power BI, Data Visualization, and Business Intelligence, following a complete end-to-end Data Analytics workflow.
